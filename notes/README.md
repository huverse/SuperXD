# 开发者的话

这个目录里的每个 .txt 文件是一封「开发者的话」。合并到 main 后由流水线 .github/workflows/notes.yml 传到中转，用户手机联网就能看到，不用发版。

文件名（不含 .txt）是这封信的编号，发出后不要改；只用字母、数字与 . _ -，例如 2026-10-24-hello.txt。

文件内容：

    标题：这封信的标题
    时间：2026-10-24 21:30

    正文从这里开始，换行与空行照写的显示。

- 标题最多 40 字，正文最多 4000 字；时间按北京时间写。
- 应用只显示最近 30 封；新信发出后 14 天内，用户在不忙的时候打开应用会弹出来一次。
- 格式不对时 CI 会失败，并说明是哪个文件、哪一处；本机可以先运行 dart run tool/developer_notes.dart --out /tmp/developer_notes.json 看看。
- 仓库是公开的，信的内容也会公开在提交历史里；不要写真实姓名、手机号、学号等实名信息。
