# playground 游乐场

定位：服务页里的小游戏（娱乐，不算工具，所以不进百宝箱）。设备级，只依赖 domain 与 theme，不依赖教务相关的任何层；自由模式免教务登录，本机成绩切换账号保留。益智板块的游戏在 puzzle 目录，登记在 puzzle/CLAUDE.md。

- [人工决策-2026-11-12 21:00:20] 用户提出游乐场（自由模式与挑战模式）、积分与灰度，并要求架构按长期设计、分类按大厂做法。用户选定的全部选项写在 playground_catalog.dart 与下面的「长期路线」，代码处的注释只写结论。

# 架构

- 三级登记：板块（益智，以后加休闲、棋牌等）→ 子类（逻辑推理、数字计算、格子谜题、移动与规划、记忆与反应、物理）→ 游戏，只在 playground_catalog.dart 一处登记，id 发出后不改（本机记录、以后的题库、挑战与积分都按 id 认）。实装一个登记一个，不放占位卡。
- 每个游戏是规则加页面两部分：
  - 规则是纯 Dart（不引 Flutter），实现 puzzle_rules.dart 的 PuzzleRules：按种子与档位出题并给参考解、按规则判定答案（不和参考解逐项比）、难度分 1–10、题面与答案编解码（解码是外部输入边界）。出题只用 PuzzleRandom（32 位运算，换语言能逐位复现）。
  - 页面用 play_frame.dart 的 PlaySession 管档位、计时与记成绩，用 PlayFrame 搭顶栏、状态行与底部操作，棋盘自己画。
- 挑战模式（服务器下发、逐关核对）直接复用规则：题库由 tool 下的工具用同一份规则离线生成导入，服务器的 TS 核对器与 Dart 共用测试向量。拼手速与物理模拟的游戏（challengeable 为假）只进自由模式。

# 长期路线（用户 11-12 选定，做到哪一阶段在哪一阶段落代码与人工决策）

1. 游乐场框架、自由模式与 17 个游戏（本阶段，纯本机、不联网）。
2. 应用账号与灰度：教务登录是登录方式之一（客户端把教务会话用服务器公钥加密交中转核对一次学号，学号只存带服务器密钥的哈希）；灰度按「开关加账号」的哈希分桶、放量只增、可一键关停、配置签名下发；应用内更新分批推送。开工前先验证教务会话换 IP 能否用。

# 文件职责

- puzzle_rules.dart：规则契约 PuzzleRules、档位 PuzzleTier（入门到专家，name 发出后不改）、出题结果 PuzzleDraw（题面与参考解）、可复现随机数 PuzzleRandom（xoshiro128**，种子按 splitmix32 式展开）与解码小工具 puzzleInt、puzzleInts。人工决策在文件头。
- playground_game.dart：登记项类型：板块 PlaygroundSection、子类 PlaygroundGroup、游戏 PlaygroundGame（名字、一句话玩法、玩法说明、图标、子类、能否进挑战、对局页）。
- playground_catalog.dart：注册表：板块、子类的显示顺序与全部游戏；人工决策在文件头（含 17 个游戏的子类归属）。
- playground_store.dart：本机记录 PlaygroundStore（playground/playground.json，先写临时文件再改名、写入排队、坏文件当没有）：每个游戏每档的最好成绩（最快用时与那局步数）、上次选的档、最近玩过（最多 playgroundRecentLimit 个）；首页卡片上显示难度最高一档的成绩（topBest）。
- play_frame.dart：对局页共用部分：PlaySession（档位、这一局的题、从第一步起计时、切后台暂停、完成记成绩）、PlayFrame（顶栏返回、游戏名、玩法、⋯里「这一题从头来」「换一道题」；状态行左边点开选难度，走过几步再换档先确认；底部操作是一排色调胶囊，包 CampusToastAnchor）、用时写法 playDuration、棋盘外框 PlayBoardBox 与共用触感 playTick、playRejected。
- play_result.dart：解开后的结果弹层 showPlayResult（成功触感、用时大字、新纪录或这一档最好、再来一局与换到下一档，不写「挑战」二字）；单独一个文件，因为弹层有自己的滚动区、不是页面。
- playground_page.dart：游乐场首页 PlaygroundPage（最近玩过一行带图标的按钮，下面按子类分组的游戏卡，两列放不下就一列，同行等高；卡上写一句话玩法与难度最高一档的最好成绩）与对局页外壳 PlaygroundGameHost（等本机记录读好再建对局页，打开时记进最近玩过）。

# 关键规则

- 出题只用 PuzzleRandom，不用 dart:math 的 Random（挑战题库与服务器要逐位复现）；规则文件不引 Flutter（tool 下的题库工具要能直接跑）。
- 判定按规则，不和参考解逐项比；每道题出之前用求解器确认可解，需要唯一解的游戏（如数织）确认唯一。
- 本机记录有上限：游戏数乘五档的最好成绩、最近玩过 playgroundRecentLimit 个，不随玩的次数增长；只有成绩，不排除出云备份。
- 对局页：计时从第一步开始；违规的操作轻震、退回，不算步数；解开后先放完收尾动画再弹结果；换档换题时页面自己清棋盘再调 session。
- 棋盘上的文字（提示数字等）用应用字体 14 号起，跟着字号缩放；格子太小时给双指缩放，不把字缩到 14 以下。
- 不写「挑战」二字到自由模式的按钮上（那是挑战模式的名字）。
