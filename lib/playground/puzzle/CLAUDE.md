# playground/puzzle 益智板块

定位：益智板块的游戏，一个游戏一个子目录，规则（纯 Dart）与对局页各一个文件。框架与契约见 lib/playground/CLAUDE.md。

# 文件职责

- hanoi 汉诺塔（移动与规划）：
  - hanoi_rules.dart：HanoiRules：入门到普通是经典开局（3 到 5 盘），困难与专家打乱开局（6、7 盘，最少步数不少于经典的一半）；hanoiMinMoves 按最大盘的位置递推最少步数，hanoiSolution 给最优解，hanoiReplay 与 hanoiLegal 判定每一步；答案每步编成「起点 × 3 + 终点」，最多 hanoiMaxMoves 步。
  - hanoi_page.dart：HanoiPage：点柱子拿起（浮到柱顶上方）、再点放下，或按住盘子直接拖（点按与拖动按原始指针自己分，外面垫一落指就赢下手势竞争的识别器，iOS 右滑返回才抢不走）；盘子扁平、塔在棋盘区垂直居中；违规轻震并晃一下退回；盘子配色以激活色为中心向两边偏色相，小盘浅大盘深；目标柱柱身着淡激活色、下面写「目标」；读屏每根柱子一个按钮；状态写步数与最少步数，可撤销。
- nonogram 数织（格子谜题）：
  - nonogram_rules.dart：NonogramRules：5、7、10、12、15 见方，随机涂一半多再按九宫格多数平滑成块，小三档左右对称；每行段数有上限（提示栏不至于太宽）、不出空行；逐行求解器 nonogramLineSolve 能解开才出（保证唯一、不用猜），推理轮数进难度分；nonogramSolveLine 是单行的动态规划推理；答案按行优先编成 0、1 字符串。
  - nonogram_page.dart：NonogramPage：单指点或拖改一串格（涂格走原始指针，外面垫一落指就赢下手势竞争的识别器，iOS 右滑返回才抢不走；锁定在起点那一行或那一列，起点已是这种标记时这一笔是擦掉；起点之后只改空格），下方分段选涂色或标叉，可按笔撤销；双指缩放平移（格子小于 44 时才能放大，第二根手指落下时这一笔作废）；提示数字 14 号字跟着格子对齐（提示栏隔一行、一列铺淡底色，两位数比格宽时只横向压窄），这一行（列）对上时变淡，手指按着的那一格所在行列加浅底；解开后叉号与格线淡出、涂色格过渡成激活色的图案；读屏导航时每格一个按钮。
- queens 八皇后（逻辑推理）：
  - queens_rules.dart：QueensRules：5、6、8、10、12 见方；随机顺序回溯取一个完整解，按随机顺序逐个锁上解里的皇后直到补法唯一，再按随机顺序拿掉多余的（留下的每个都少不了），高三档出几道候选留提示最少、试探最深的；求解器 queensSolve 先推「某行某列只剩一格」、推不动挑最窄的行或列试探，数到第 2 个解就停，试探分支数进难度分（口径在 difficulty 的注释）；queensAttack 判两个皇后互相攻击；题面 given 与答案都是每行的列（-1 是没有），边长上限 queensMaxSize，解码拒收锁定皇后互相攻击的题。
  - queens_page.dart：QueensPage：点空格放、再点拿掉（按住皇后超过长按时长只看攻击范围，松手不拿掉），锁定的点了轻震并晃一下；冲突不拦，冲突的皇后标警示色、两两之间连一条淡线；最后碰过的皇后用不透明的淡激活色铺出攻击范围（盖住深浅格才读得出）；自己放的是激活色圆棋子加白色王冠，锁定的是垫底板的墨色王冠；格子不到 48 时双指放大到 48，放大后单指平移（认领这次触摸，不让 iOS 右滑返回抢）；解开后皇后按行依次轻轻亮一下再弹结果；读屏每格一个按钮；状态写「已放 5/8」，可按步撤销。
- ice 冰面滑行（移动与规划）：
  - ice_rules.dart：IceRules：6、7、8、10、12 见方，岩石按 15%–25% 随机撒、起点随机；iceDistances 以停下的位置为状态广度优先求每格最少步数，在最少步数落在这一档区间的格里挑终点（区间写在 _least，入门 3–5 到专家 14 起），没有就换一张图；iceSlide 滑到撞上岩石或边界才停（滑不动是原地），solved 按序重放、只看最后停在哪；难度分 iceDifficulty 按最少步数加边长，五档分段不重叠；答案每步一个方向（0 上、1 右、2 下、3 左），最多 iceMaxMoves 步。
  - ice_page.dart：IcePage：在棋盘上滑动（识别器手指一落下就赢下手势竞争，iOS 的右滑返回抢不走）或点下方十字方向键推小企鹅；滑行时长按距离、前快后慢，撞停轻压回弹，滑不动轻震并朝那边顶一下，撤销倒放滑回；解开时在终点轻跳、光圈漾开，再弹结果；冰面、带雪的卵石、终点与企鹅的颜色全从配色推出，静态层拼成几条路径按题缓存、只有企鹅逐帧重画；读屏读棋子与终点的行列。
- lights 点灯（格子谜题）：
  - lights_rules.dart：LightsRules：3 到 7 见方；从全亮随机点几个不同的格得开局（一定解得开），lightsSolve 在 GF(2) 上高斯消元求最少点法（零空间不为零的 4×4、5×5 枚举取最省），最少下数落在这一档的区间才用（区间写在 _least）；难度分按格数与最少下数；lightsReach、lightsPress、lightsReplay 是翻转与重放；题面编成边长加 0、1 串，答案是依次点的格，最多 lightsMaxPresses 下，解码拒收全亮与点不全亮的题面。
  - lights_page.dart：LightsPage：灯排在一张卡片上，整张卡按格均分作热区（缝与卡边归最近一格），落点按按下的那一格算；按下处浮浅色方块、松手淡出；被翻的几盏 180ms 从当前亮度续接过渡；亮灯是激活色推出的圆灯加格内柔光（一盏一个径向渐变，不经离屏贴图），灭灯是灰色实心圆带细边、拼成一条路径画；全亮后从中心向外依次亮一下再弹结果；状态写步数与最少步数，可撤销；读屏每格一个按钮；减少动画时直接到位。
- knights 骑士与无赖（逻辑推理）：
  - knights_rules.dart：KnightsRules：2 到 6 人（名字按座位叫甲到己）；句式 KnightsClaimKind（code 发出后不改）随档加：是骑士或无赖、我和谁同类或不同类，普通加恰好、至少、至多几个骑士，困难与专家加如果…那么、至少一个是无赖、转述；出题先定身份再给每人挑一句和身份一致的话，枚举全部 2^N 组只有一组成立才用，knightsReasoning 模拟单句推与联合几句推，按档限制开头能直接定下几人、最多联合几句；solved 按「每句话真假与说话人身份一致」判；题面只存句式与参数，解码校验参数并拒收不唯一的题；难度分以人数为主、联合推理量够多再加 1（口径在 difficulty 的注释）。
  - knights_page.dart：KnightsPage：每人一张卡（自绘头像：骑士戴盔、无赖戴面具、未定是中性）写他说的话（按结构生成口语、按意思分段换行），卡上「骑士 / 无赖」两个色调胶囊直接选、再点取消，可按步撤销；全部定下就判，错了不给答案、只把话和身份对不上的人标警示色并轻震，对了卡片依次翻一下再弹结果；状态写「已定 3/5」；读屏每张卡读名字、话与当前标记。

# 加一个游戏的步骤

1. 在本目录建子目录，照 hanoi 目录的命名写规则文件（实现 PuzzleRules，只用 PuzzleRandom 出题，出题前用求解器确认可解，需要唯一解的确认唯一）与对局页文件（PlaySession 加 PlayFrame，棋盘自己画；文字 14 号起、触区至少 48 或可放大；违规用 playRejected，落子用 playTick；解开先放收尾动画再 showPlayResult）。
2. 在 playground_catalog.dart 登记到用户定的子类里（id 发出后不改），写一句话玩法与玩法说明；服务器核不了的（拼手速、物理模拟）challengeable 写假。
3. 测试放这个游戏自己的文件（文件名用 playground_ 加游戏 id 加 _test，几个游戏并行开发时互不冲突）：规则部分测每档出题可解、参考解通过、违规不算、编解码往返与坏输入，页面部分走完一局并弹出结果；汉诺塔与数织的写法在 playground_rules_test.dart 与 playground_ui_test.dart。
4. 在本文件与 lib/playground/CLAUDE.md 的测试一节登记，在 CHANGELOG 的 Unreleased 下记一条（几个游戏并行开发时由合并的人统一写一条）；在模拟器上 360dp 加 1.3 倍字号与 411dp 标准两种条件下、深浅两色看过再交。

# 关键规则

- 棋盘上的拖动（涂、拖、滑）一律在棋盘范围内一落指就赢下手势竞争（EagerGestureRecognizer 或自己写的同类识别器），否则 iOS 的页面任意位置右滑返回（约 18dp 就认横向拖动）会抢走手势、整页滑走。
- 难度分 1–10 的口径：按求解要走的步数与推理深度，同档的题分数相近，档与档之间单调上升；挑战模式计分直接用它，改口径前先看 lib/playground/CLAUDE.md 的长期路线。
- 视觉照设计语言：颜色取 CampusPalette 的角色、不写死色值（棋子配色可从激活色推出）；动效克制、减少动画时直接到位；一次画完的图形拼成一条路径，不在 paint 里逐个画小图形。
