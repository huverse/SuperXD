- 色调：默认苔灰，可选雾蓝、藕粉、暮紫、燕麦；配色在我的-界面选择，所有颜色取当前CampusPalette主题角色，禁止静态旧色残留。

# 2. 原则

1. 玻璃只表示「这层浮在内容上」。
2. 可读性高于质感。对比度不够的颜色不能当文字，也不能当按钮底。
3. 动效只解释变化。弹窗、模糊与遮罩用同一路由进度正反向同步；页面退场不在前半段提前清空。
4. 页面不写散装色值、字号、间距、圆角、时长。

# 3. 主题约定

暖灰基底和文字层级保持稳定；更换强调色必须重新验证文字在最亮/最暗背景上的对比度。背景云雾采用可辨的大面积冷暖珠光与柔边交融，随五套主题适配，不决定正文颜色，不用高饱和霓虹或快速扫光。

# 4. 颜色角色

完整配色角色以lib/theme/campus_palette.dart为准。以下为默认苔灰，不用于覆盖用户其他选项：
- backgroundTop #F1F0ED，backgroundBottom #E8E7E3
- surface #F9F8F5，surfaceSelected #E1E5DC
- onSurface #292B2A，onSurfaceVariant #565B57
- primary #49584E，onPrimary #FFFFFF

- fogSage #AFBDA9，fogChampagne #D8C7AE

正文和必要辅助文字对比度至少4.5，图形状态不能只靠颜色。暗色使用独立的低亮度基底、分层提亮表面、柔白文字与低饱和行动色；玻璃、云雾和系统栏同步适配，取当前色彩角色而非静态反色。

# 5. 玻璃

导航/底栏使用少量真实或标准玻璃层，弹层背景轻模糊；内容卡片用高遮色细磨砂，不逐项模糊与折射。禁止glass-on-glass。

亮色：

- 着色glassTint，按导航与内容分层；内容面不透明度约0.91
- 固定导航面模糊约8；高对比度和减少动画使用实色替代
- 描边 1 像素白色，不透明度 0.70
- 不能模糊时的实色 #F3F7F9

暗色：

- 着色 #1A242B，不透明度 0.80
- 固定导航面模糊约8；高对比度和减少动画使用实色替代
- 描边 1 像素白色，不透明度 0.14
- 实色退路 #1A242B

规则：

- 顶栏和底栏可以同时模糊
- 弹层打开时只模糊弹层。顶栏和底栏改实色
- 会话页没有底栏。顶栏可以模糊，输入栏必须实色。输入栏再模糊就会和键盘、顶栏叠成三层
- 系统降低透明度时，全部走实色

- 待办是行
- 通知只露最近两条，整行可点，进消息。不在今天页做第三套通知样式

# 8. 动效

应用内业务图标统一Lucide，状态形变使用基于Morphicons的Flutter适配Morphnext；导航提交选中后短形变，静态图标不循环。桌面图标不在本轮范围，系统控件未开放的勾选与箭头保留原生语义。

等待按场景固定：按钮双纽线、页面首次读取三瓣玫瑰、较长同步利萨茹。单色轻拖尾、150ms后显示装饰动画、业务完成即结束；局部刷新保留同一范围旧内容，真实阶段不伪造百分比。

曲线预采样并局部重绘，隐藏页面及后台停帧，减少动态效果用静态轨迹和任务文字。授权、上游版本及改动说明见assets/third_party_notices.txt，应用“我的”可查看。

单位毫秒。进入 emphasized decelerate，退出 emphasized accelerate。不用回弹。

- 按下、选中、开关：150
- 小组件进入：250
- 小组件退出：200
- 底栏页面转场：240，12dp水平位移加淡入淡出，保留分支Navigator和阅读状态，旧分支不接收点击
- 所有独立页面360ms进入、320ms返回，覆盖切换账号、编辑、历史、成绩、协议和许可；弹窗300ms，支持系统返回和减少动画
- 上限 400

普通转场禁止：列表逐项飞入、循环高光、两段装饰动画同时演、弹簧回弹。

课表不走「位移不超过 8」。被点的卡片要沿真实距离变成侧栏，位移限制会造成先淡掉再出现。课表的规则在第 13 节，时长仍不超过 400。

# 10. 明确不做

- 内容区玻璃，长列表逐项模糊
- 种子色当亮色文字或亮色按钮
- 一周七列的小格矩阵。周是按天看课程
- 会话页使用玻璃输入栏
- 换校时改正文黑灰
- 小于 14 的字，小于 48 的热区
- 弹性过冲和列表 stagger
- 课表动画拆成两段首尾相接。那就是间断
- 只能靠再次长按才能关掉课程详情

# 13. 课表（2026-09-24 更新）

范围为天、学期、学年；不提供独立周档或七列周矩阵。每次阅读一天课程。

- 从服务的课表卡片进入，根级返回服务，底栏不出现在课表内。
- 月与周在左侧同一列，点月展开周。周项两行：第N周、起始日期。第1周按开学日所在周的周一计算；周中开学不展示开学前的日期。
- 周项至少48dp热区；上下间距随可用高度在6–12dp内变化，窄屏或大字时滚动，不压缩字。
- 正课和空课等宽等高；按实际剩余空间、文本宽度和字号算统一高度，默认四卡优先首屏完整显示；长文本、大字号或更多卡片允许必要滚动，不压到14以下或隐藏信息。
- 卡片第一行统一「第x–x节」，第二行显示这些节次对应的已知作息时间；空课同样显示时间，缺作息显示「作息时间未设置」。1–2空课写「早八没课哦~」。
- 课程名称、时间范围、教室、教师清晰分层。仅今天正在上的课和最近下一节课在右侧显示剩余分钟；跨日或没有作息不伪造倒计时。
- 日期栏为独立横向滚动组件，单项至少48dp，显示月/日，选中日高亮；页面滑动同步选中日，日期栏自动让选中项可见。
- 「今天」是显式回位命令：即使选中日没变化、只是日期栏被滑远，也强制回到今天；跨学期同时恢复当前学期、日期、课程和周/月。
- 日期栏节点与高度在切范围、切周时稳定；有数据的学期不先移除再插回。显式跳到远日期只提交最终日期，不逐天触发中间月份。
- 单次日期/范围转场250–350ms，保留旧内容过渡，不重做网络请求。不在动画帧重新筛全课表。减少动画模式下尊重系统设置。
- 学年根是学期卡，下一年向年份增大方向；选学期读取该学期的课表和开学日，禁止套用另一学期的开始日。
- 开学日选择默认该学期已保存日期，未设置才用校园今天；中文日历，保存后弹窗显示新日期与第1周起点。
- 详情按具体课程安排的稳定标识打开；其他卡片收拢，关闭后恢复原列表与滚动位置。点击详情外空白、系统返回、顶栏返回均只关闭详情；详情内点击/滚动不误关闭。
- 关闭详情后，返回收起所选月；学年内再返回学期列表；根级离开课表。
- 整天无课在课程内容区居中显示「这天没课」和「是放假了还是?反正今天一定很爽啦!」。未同步、缺少开学日、读取失败不冒充无课。

# 15. 记住账号与会话恢复

- 首次勾选必须先确认：「SuperXD本地版的记住账号功能将会把账号鉴权数据加密存储在本地」。取消不勾选，确认且认证成功才保存。
- 使用flutter_secure_storage和系统KeyStore，按教务来源及服务端账号身份隔离；业务SQLite与日志不存密码。安全存储失败不降级明文，提示没有保存成功。
- 本地加密不等于网络加密；当前教务使用HTTP，登录说明必须明确这一限制。
- 仅明确会话失效才自动登录。同账号并发只进行一次认证，成功后每个被拒绝的教务读取至多重放一次，不重放本地编辑、导入或确认覆盖操作。
- 验证码、短信、错误密码、锁定或无法解密均停止并转人工，禁止循环尝试。主动退出或关闭记住立即删除该账号保存的凭据，保留业务数据；在途旧登录结果不可使账号复活。
- 启动优先恢复本地会话，不每次联网验证。已有记住凭据但缺会话时尝试一次；失败显示提示并停止下次启动自动反复尝试。
- Android云备份和设备迁移排除本插件的凭据密文及包裹密钥文件。
