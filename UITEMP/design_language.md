# 2. 原则

1. 玻璃只表示「这层浮在内容上」。
2. 可读性高于质感。对比度不够的颜色不能当文字，也不能当按钮底。
3. 动效只解释变化。返回手势跟手：拖动中页面随手指平移，松手从当前位置续接返回或回弹。弹窗、模糊与遮罩用同一路由进度正反向同步；页面退场不在前半段提前清空。页面推入、返回与底栏分支切换用临界阻尼弹簧曲线（同鸿蒙 Navigation 默认转场、iOS 推入）：起步即跟上、长尾减速、不回弹，返回同样先快后慢。会被打断的变化（玻璃换档、壁纸外观）从当前值续接，不归零、不跳变。
4. 页面不写散装色值、字号、间距、圆角、时长。

# 3. 主题约定

暖灰基底和文字层级保持稳定；更换强调色必须重新验证文字在最亮/最暗背景上的对比度。背景云雾采用可辨的大面积冷暖珠光与柔边交融，随五套主题适配，不决定正文颜色，不用高饱和霓虹或快速扫光。

自定义壁纸（我的—界面—背景，默认仍是云雾）：
- 静态图铺满屏幕，不再循环；高对比度时不显示，回到基底色。
- 壁纸不决定文字颜色：文字仍取主题色，壁纸按区域铺一层主题基底色的淡化。每格淡化量按该格最不利的像素算，使正文、次要文字和主色文字不低于4.8:1；相邻格平滑过渡，不显网格。
- 模糊与透明度都是0–100%的连续滑杆，拖动时背景实时变化、松手保存；透明度只在可读下限与完全盖住之间插值，0%即下限，任何取值文字都不低于4.8:1。
- 云雾与壁纸互换、换图时背景交叉淡化，新图解码完成后才淡入。
- 只经系统照片选择器读取选中的一张，不申请存储权限；本机只保留一张，最大20MB。

# 5. 玻璃

导航与控件层使用液态玻璃，内容卡片用高遮色细磨砂，不逐项模糊与折射。禁止glass-on-glass：父玻璃内的控件只做vibrancy，不再采样背景。唯一例外是底栏选中指示器：拖动和回位期间升起为玻璃透镜，按速度挤压拉伸（与iOS底栏一致），静止后落回着色胶囊；磨砂和实色档不升起。

材质分三类角色，参数统一由lib/theme/campus_glass_material.dart给出，组件不写死：
- navigation：顶栏、底栏。满档不加色散，标签区不出色边。
- control：按钮、开关、标签。
- overlay：菜单、底部弹层、弹窗、提示条。满档时雾化完全盖住底层，只透出模糊色块，不透出底下的文字；浅色压在遮罩上会发灰，整块均匀提亮0.65，五套配色实测次要文字与文字按钮不低于4.85:1。

档位分四档，由lib/theme/campus_glass_tier.dart决定（玻璃与实色互换、自动模式升降档、按钮禁用都经同形状实色盖板过渡：盖满才换、再揭开，不给玻璃套半透明图层）：
- 满档：以iOS 27常规材质为底（雾化、轮廓、高光），按当前配色轻着色，不加色散；背景饱和浅色1.4、深色1，选中与按下的控件底色铺厚。
- 标准：轻量着色器，无色散。
- 磨砂：模糊加饱和，不跑自定义着色器。
- 实色：glassFallback。

玻璃效果设置在我的—界面，三档：
- 自动（默认）：按实测帧耗时在满档、标准、磨砂之间升降。
- 完整：固定满档。
- 简化：固定磨砂。

上次满档运行后进程崩溃、原生崩溃或ANR时，本版本内上限降为标准，升级后重试。高对比度、无障碍导航、减少动画时一律实色。

亮色：

- 着色glassTint，按导航与内容分层；内容面不透明度约0.91
- 固定导航面模糊约8；高对比度和减少动画使用实色替代
- 描边 1 像素白色，不透明度 0.70
- 不能模糊时的实色 #F3F7F9

暗色：

- 着色 #1A242B，不透明度 0.80
- 固定导航面模糊约8；高对比度和减少动画使用实色替代
- 描边 1 像素白色，不透明度 0.14
- 实色退路 #1A242B

规则：

- 顶栏透明无底板（2026-10-03），只有栏里的按钮是玻璃；底栏是悬浮玻璃
- 弹层打开时只模糊弹层，底栏改实色：实色盖板随遮罩渐显，盖满才换实色；弹层一开始关闭就渐隐回玻璃，与遮罩一起淡出，不在遮罩消失后突变
- 会话页没有底栏。顶栏可以模糊，输入栏必须实色。输入栏再模糊就会和键盘、顶栏叠成三层
- 系统降低透明度时，全部走实色

# 8. 动效

应用内业务图标统一Lucide，状态形变使用基于Morphicons的Flutter适配Morphnext；导航提交选中后短形变，静态图标不循环。桌面图标不在本轮范围，系统控件未开放的勾选与箭头保留原生语义。

等待按场景固定：按钮双纽线、页面首次读取三瓣玫瑰、较长同步利萨茹。单色轻拖尾、150ms后显示装饰动画、业务完成即结束；局部刷新保留同一范围旧内容，真实阶段不伪造百分比。

曲线预采样并局部重绘，隐藏页面及后台停帧，减少动态效果用静态轨迹和任务文字。授权、上游版本及改动说明见assets/third_party_notices.txt，应用“我的”可查看。

单位毫秒。进入 emphasized decelerate，退出 emphasized accelerate。除玻璃控件外不用回弹。

# 15. 记住账号与会话恢复

- 首次勾选必须先确认：「SuperXD本地版的记住账号功能将会把账号鉴权数据加密存储在本地」。取消不勾选，确认且认证成功才保存。
- 使用flutter_secure_storage和系统KeyStore，按教务来源及服务端账号身份隔离；业务SQLite与日志不存密码。安全存储失败不降级明文，提示没有保存成功。
- 本地加密不等于网络加密；当前教务使用HTTP，登录说明必须明确这一限制。
- 仅明确会话失效才自动登录。同账号并发只进行一次认证，成功后每个被拒绝的教务读取至多重放一次，不重放本地编辑、导入或确认覆盖操作。
- 验证码、短信、错误密码、锁定或无法解密均停止并转人工，禁止循环尝试。主动退出或关闭记住立即删除该账号保存的凭据，保留业务数据；在途旧登录结果不可使账号复活。
- 启动优先恢复本地会话，不每次联网验证。已有记住凭据但缺会话时尝试一次；失败显示提示并停止下次启动自动反复尝试。
- Android云备份和设备迁移排除本插件的凭据密文及包裹密钥文件。
